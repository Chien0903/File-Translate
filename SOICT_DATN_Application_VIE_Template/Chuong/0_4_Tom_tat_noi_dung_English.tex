\begin{center}
    \Large{\textbf{ABSTRACT}}\\
\end{center}
\vspace{1cm}
In the context of international economic integration, many enterprises frequently need to process texts and documents in different languages. These documents may exist in various formats such as DOCX, XLSX, PPTX, PDF, images, or plain text, while also requiring fast, accurate, and manageable translation. However, using scattered translation tools or manual translation often makes it difficult to store translation history, standardize specialized terminology, and manage users within an enterprise environment.

To address the above problem, this project follows the approach of building a web-based system that supports multilingual translation for text and office documents in an enterprise environment. The system consists of a user interface, a backend service, and a specialized document-processing component. This approach helps integrate the translation workflow, terminology management, user management, and translated-result storage into a unified platform.

The system provides main functions such as user authentication, text translation, file translation, file upload to external storage through S3, PDF format conversion, translated-file history management, user management, notifications, and terminology library management. The translation workflow uses Google Cloud Translation, terminology libraries stored on Google Cloud Storage, ConvertAPI, and libraries for processing DOCX, XLSX, PPTX, PDF, image, and OCR content. Users can choose to translate with the common terminology library, with a private terminology library, or without using a terminology library, and then download the translated results.

The main contribution of this project is the development of an integrated system for multi-format document translation, terminology management, and role-based web operation. The achieved result is a system that completes the core functions within the experimental scope and can support enterprises in managing and translating multilingual documents.
